# Climate Change Analysis: East Africa Regional Study

This repository contains an Exploratory Data Analysis (EDA) of climate trends across East Africa, focusing on Ethiopia and its neighboring countries (Kenya, Sudan, Nigeria, and Tanzania). 

The goal of this project is to identify temperature patterns and regional heat profiles from 2015 to 2026.

# Repository Structure

- **.github/workflows/**: CI/CD pipeline ensuring the project environment is stable.
- **notebooks/**: 
    - Individual EDA notebooks for each country.
    - `comparison_analysis.ipynb`: A regional deep-dive comparing all countries.
- **requirements.txt**: All Python dependencies required to run the analysis.
- **.gitignore**: Configured to exclude large data files and virtual environments.
